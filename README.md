# PORTOFOLIO
# 🕹️ Malice Portfolio Website

> *"PLAYER 1 READY"* — Sebuah situs web portofolio pribadi interaktif berkonsep *pixel-art* / *retro gaming* untuk menampilkan berbagai proyek kreatif, karya pengembangan game, serta keahlian teknis.

---

## 🚀 Fitur Utama
* **Retro Gaming Aesthetic:** Dilengkapi dengan font bergaya klasik (`Press Start 2P`), efek *scanlines* monitor jadul, dan latar belakang animasi bintang bergerak (*pixel background*).
* **Dynamic Project Rendering:** Daftar proyek dimuat secara dinamis langsung dari struktur data JavaScript.
* **Interactive Modal Pop-up:** Detail proyek dapat diklik untuk membuka jendela pop-up informasi lengkap beserta tautan repositori GitHub.
* **Scroll-Powered Animations:** Menggunakan **Intersection Observer API** untuk memberikan efek transisi kemunculan elemen yang mulus saat halaman digulir.
* **Fully Responsive:** Tata letak fleksibel yang dirancang menggunakan CSS Grid dan Flexbox agar nyaman diakses melalui perangkat desktop maupun seluler.

---

## 🛠️ Teknologi yang Digunakan
Proyek portofolio ini dibangun menggunakan teknologi web standar modern tanpa *framework* berat:
* **HTML5** — Struktur utama halaman web.
* **CSS3** — Desain tata letak, variabel kustom (*custom properties*), *media queries*, dan animasi visual.
* **JavaScript (Vanilla)** — Logika interaktivitas, rendering data dinamis, dan sistem *modal pop-up*.
* **Google Fonts** — Tipografi menggunakan *Montserrat* dan *Press Start 2P*.
